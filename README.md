# 小米手环 9 Pro 羽毛球挥速测速器（Xiaomi Vela）

基于 **Xiaomi Vela OS** 快应用开发的轻量级羽毛球挥速测速工具，适配 **小米手环 9 Pro（336 × 480）**，免拆机、可完全离线使用。

## 功能特性

- **三轴加速度采集**：使用 `@system.sensor` (`interval: 'game'`, 约 50Hz) 捕捉挥拍爆发期。
- **自动单位探测与重力跟踪**：前 10 帧自动区分 `m/s²` 与 `g`，待机态慢速跟踪重力基准并在挥拍期间冻结。
- **三状态机 + 短窗口积分**：`IDLE -> SWINGING -> COOLDOWN`，过滤日常抖动与 `500ms` 内的回拍二次尖峰。
- **运动场景交互**：
  - 监测中保持常亮（`@system.brightness`），退出/暂停自动释放传感器与常亮锁以省电。
  - 挥拍短震提示、刷新最高纪录长震提示（`@system.vibrator`）。
  - 本地保存最近 20 条记录、历史最高挥速及标定设置（`@system.storage`）。

## 1. 本地运行算法测试

工程核心算法模块 `src/common/swingDetector.js` 不依赖手环环境，可直接在电脑上用 Node.js（v18+）运行单元测试：

```bash
npm test
```

## 2. 编译打包 `.rpk`

1. 下载并安装小米官方 **AIoT-IDE**（基于 VS Code）。
2. 在 AIoT-IDE 中打开当前项目目录，目标设备选择 **小米手环 9 Pro（336 × 480）**。
3. 先在模拟器中验证界面排版、页面跳转和按钮交互。
4. 点击 IDE 菜单中的打包/构建命令生成 `.rpk` 安装包。

## 3. 侧载安装到手环

1. 可使用社区常见工具（如 **AstroBox** 或 **表盘自定义工具**）连接小米手环 9 Pro。
2. 选择上一步打包生成的 `.rpk` 文件安装到手环。
3. 建议将手环**紧戴在持拍手手腕**上（比日常多扣紧一格表带），打开手环上的 **羽球测速** 即可开始测试。

## 4. 240fps 慢动作简易标定

由于手环戴在手腕且采样率约 50Hz，默认标定系数 `K = 2.2` 为经验初始值，可按以下方法花 5 分钟校准到接近个人发力习惯：

1. 手机开启 **240fps 慢动作录像**，侧向架稳，空挥 3~5 次平抽或高远球。
2. 逐帧数出拍头经过 1 个标准球拍全长（约 `0.675m`）所用的帧数 $N$：
   $$v_{\text{real}} \approx \frac{0.675}{N / 240} \times 3.6 \text{ (km/h)}$$
3. 对比手环读数，在手环 **设置 -> 标定系数 K** 中按 `0.1` 步进微调（例如手环读数偏低就调大 `K`），让两者大致对齐即可。
